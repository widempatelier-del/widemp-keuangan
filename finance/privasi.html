Kebijakan Privasi WIDEMP FINANCE

Berlaku sejak 25 November 2026

WIDEMP FINANCE adalah aplikasi web pencatatan keuangan proyek yang dibuat oleh Widemp Atelier. Halaman ini menjelaskan data apa yang dipakai aplikasi dan di mana data itu disimpan.

Data yang Anda masukkan

Data proyek, termin, transaksi, invoice, kwitansi, dan pengaturan usaha yang Anda ketik disimpan di perangkat Anda (penyimpanan browser) dan, bila Anda menghubungkan Google Drive, di Google Drive akun Anda sendiri dalam folder yang dibuat oleh aplikasi. Kami tidak memiliki server untuk menyimpan data tersebut dan tidak dapat melihatnya.

Akses Google Drive

Saat Anda menekan "Hubungkan Drive", aplikasi meminta izin Google drive.file. Izin ini hanya memungkinkan aplikasi membuat, membaca, dan memperbarui file yang dibuat oleh aplikasi ini. Aplikasi tidak dapat melihat atau mengubah file lain di Drive Anda. Data dari Google hanya dipakai untuk menyinkronkan catatan keuangan Anda antar perangkat dan menyimpan PDF yang Anda pilih untuk disimpan, tidak dipakai untuk tujuan lain, tidak dijual, dan tidak dibagikan kepada pihak mana pun.

Penggunaan informasi yang diterima dari Google API mematuhi Google API Services User Data Policy, termasuk ketentuan Limited Use.

Mencabut akses & menghapus data

Anda dapat mencabut akses kapan saja melalui pengaturan izin akun Google atau tombol "Putuskan" di aplikasi. Data di perangkat dapat dihapus dengan menghapus data situs di browser, dan data di Drive dengan menghapus folder aplikasi di Google Drive Anda.

Versi demo

Versi demo tidak terhubung ke Google Drive. Data contoh dan apa pun yang Anda ketik di demo hanya tersimpan di browser yang sedang dipakai.

Kontak

Pertanyaan tentang privasi: hubungi Widemp Atelier melalui WhatsApp.
